## Question 1 (GradedCheckboxQuestion)

Which of the following can address overfitting?

- [x] Collect more training data ✅correct
  > Feedback: Nice work If the model trains on more data, it may generalize better to new examples.
- [ ] Remove a random set of training examples
- [x] Apply regularization ✅correct
  > Feedback: Nice work Regularization is used to reduce overfitting.
- [x] Select a subset of the more relevant features. ✅correct
  > Feedback: Nice work If the model trains on the more relevant features, and not on the less useful features, it may generalize better to new examples.
