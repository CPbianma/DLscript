# Machine Learning Flight Simulator (Introduction to the Quizzes)

Welcome to your machine learning "flight simulator"!

We use this term as an **analogy**. Think about how pilots train: they use flight simulators to safely practice many different flying scenarios in a short amount of time. This helps them gain valuable experience much faster than if they only flew real planes.

![](https://d3c33hcgiwev3.cloudfront.net/imageAssetProxy.v1/gJ2JXXtEEeeumw4MySoK5g_7e0b28fe11ec263aed27efe83588a1fe_Screen-Shot-2017-08-07-at-12.45.11-AM.png?expiry=1791554927805&hmac=VlVQXFuNvLGGpuUFi2WTs2ouqL3UotSrBNqjis8IAx8)

Similarly, these quizzes are designed to accelerate your learning. Each one presents a detailed case study, allowing you to practice making key decisions in a machine learning project. It's a way for you to gain practical experience with challenges that you might otherwise only encounter after years on the job.

So, while we call this a "flight simulator," your challenges won't involve airplanes. Instead, you'll apply your skills to the following real-world case studies:

* **Week 1:** Bird Recognition in the City of Peacetopia
* **Week 2:** Autonomous Driving

*Personal note from Andrew**: I’ve found practicing with scenarios like these to be useful for training PhD students and advanced Deep Learning researchers. This is the first time this type of “airplane simulator” for machine learning strategy has ever been made broadly available. I hope this helps you gain “real experience” with machine learning much faster than even full-time machine learning researchers typically do from work experience.*
