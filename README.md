# DLscript — Coursera ML/DL 课程材料

机器学习与深度学习专项课程的学习材料与笔记，用于桌面端与笔记本多设备同步。

## 目录结构

- `coursera-materials/01-machine-learning-specialization/` — 机器学习专项课程（监督学习 / 高级学习算法 / 无监督学习与强化学习）
- `coursera-materials/02-deep-learning-specialization/` — 深度学习专项课程
- `coursera-materials/manifest.json` — 材料清单
- `coursera-materials/progress.md` — 学习进度记录
